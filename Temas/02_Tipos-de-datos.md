# Tipos de datos:
Existe varios tipos de datos en Python que nos 
ayudan en diferentes ocasiones para diferentes 
casos

ENTRE ELLOS ESTAN:

### Integer:

Un integer o int es un numero completo
no tiene decimales y contiene el numero 0
los numeros positivos y negativos

year = 2026

age = 23

Un numero de punto flotante o float, es un

### String:

Un string o str se utiliza para almacenar
texto. Los strings se encierran entre comillas 
dobles o simples

username = "yo merenges"

### Boolean:

Un tipo de dato boolean o bool almacena un
valor que solo puede ser verdadero o falso
en Python se escribe con mayusculas la inicial
True o False

pythonmalo = False

pythonbueno = True
