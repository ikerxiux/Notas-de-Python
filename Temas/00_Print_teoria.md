## Comentarios
Los comentarios son muy importantes en programacion
por que se utilizan para documentarlo que hace nuestro
codigo. Cuando se ejecuta el programa los comentarios
se ignoran. En Python podemos crear comentarios 
usando #
- [EJEMPLO A-2](https://github.com/ikerxiux/Notas-de-Python/blob/main/Ejemplos/00_print.py)
Python solo ignora todo lo que esta en esa linea
despues de #
### Comentarios en varias lineas
Al usar # Python solo ignora lo que esta 
en esa misma linea pero para que el comentario
sea de varias lineas se ocupa """ o '''
de esta forma ignora lo que esta dentro de
"""
