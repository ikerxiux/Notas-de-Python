## Snake_case
En Python a la hora de asignar un valor
hay que tener mucho cuidado de como lo 
escribimos por que no es lo mismo 

Age = 23

a

age = 23

ya que por la letra mayuscula y miniscula
son temas completamente diferentes por eso
en Python para evitar errores se recomienda
poner todo en minusculas.
Y ahora si entra snake_case que se usa
para poder referirse a algo de manera mas
sencilla por ejemplo
